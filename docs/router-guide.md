# TanStack Router

본 프로젝트는 실사용자가 존재하는 데이터 중심의 PWA 앱으로, 서비스의 안정성과 사용자 경험(UX)을 극대화하기 위해 **TanStack Router**를 사용하였습니다.

- 모든 경로와 파라미터를 타입 시스템 내에서 관리하여, 오타나 데이터 누락으로 인한 런타임 에러를 차단한다.
- 대규모 앱의 복잡한 검색/필터링 쿼리를 Zod 스키마로 검증 및 파싱하여, URL 데이터를 안전하고 구조화된 객체로 관리한다.
- 라우팅 시작과 동시에 데이터를 패칭하는 Loader와 Pre-fetching 기능을 통해, 네트워크 지연을 최소화하고 네이티브 앱 수준의 끊김 없는 전환을 제공한다.
